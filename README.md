# 🚀 Misión Musical Espacial

Juego educativo de música para estudiantes de **4.º a 7.º grado**. Zum, un alienígena, necesita ayuda para recuperar los 5 fragmentos de la *Canción de Armonía* que robaron los Piratas del Silencio.

## ▶ Jugar

**https://jomaker2025-hash.github.io/game/**

Funciona en el navegador de computadoras, tablets y celulares. No hace falta instalar nada. Se recomienda usar audífonos o parlantes.

## 🪐 Planetas y temas

| Planeta | Grado | Tema |
|---|---|---|
| Planeta Do‑Re‑Mi | 4.º | Las notas Do, Re, Mi, Fa y Sol (constructor de beats) |
| Planeta Eco | 5.º | Sonidos graves y agudos, notas largas y cortas |
| Planeta Pulso | 6.º | Tempo rápido y lento, accelerando y ritardando |
| Planeta Ritmo | 7.º | Figuras rítmicas: blanca, negra y corchea |
| Nebulosa Orquesta | Bonus | Familias de instrumentos |
| Lluvia de Meteoros | Todos | Modo arcade: toca canciones con las notas que caen |

En cada planeta hay un **laboratorio** para experimentar y **3 niveles** de 5 desafíos.

## 👩‍🏫 Para docentes

- **Modo profesor** (en la pantalla de inicio): desbloquea todos los niveles para revisar el juego rápido.
- El progreso se guarda en el navegador de cada dispositivo.
- Todo el sonido se genera en el navegador con Web Audio API; no usa archivos de audio.

## 🛠️ Técnico

Es un solo archivo `index.html` (HTML, CSS y JavaScript) sin dependencias. Solo carga las tipografías de Google Fonts y, si no hay internet, usa las del sistema.
